## **Artifact 3: The Coaching Session Protocol**
**Purpose:** The script for the Instructor-Student meeting 2 weeks prior to their slot.

**MEETING AGENDA (30 Minutes)**

**1. The Tech Certification (10 Minutes)**
*   *Action:* Student shares screen and runs their tutorial workflow live.
*   *Instructor:* "Export the JSON and send it to me now."
*   *Validation:* Instructor imports JSON. Does it run?
    *   **PASS:** File is certified as the "Golden File."
    *   **FAIL:** Student has 48 hours to fix bugs.

**2. The Content Review (10 Minutes)**
*   *Video Check:* Watch the "Pre-Watch Video" selected by the student.
    *   *Instructor:* "Is this accurate? Is it too long? Is it too complex?" (Approve/Reject).
*   *Strategy Check:* "Show me where your two 'Hands-Off' concept explanations are."

**3. The "Crash" Plan (5 Minutes)**
*   *Instructor:* "What happens if the API fails during class?"
*   *Student:* Must show their backup plan (e.g., "We have a saved static JSON file to load into the next node").

**4. Role Definition (5 Minutes)**
*   **Cycle 1 Teams:** "I will co-pilot with you. I will interrupt if the class gets lost."
*   **Cycle 2 Teams:** "I am a silent observer. You own the room. Good luck."
